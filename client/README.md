# Client — Протокол-ассистент

Electron-приложение (голый renderer, без фреймворка): захват микрофонов, live-транскрипт
(partial/stable/final), сценарий анкеты с TTS, плеер с привязкой аудио↔текст, редактирование.

## Запуск

```powershell
cd client
npm install
npm start
```

По умолчанию подключается к бэкенду на `http://127.0.0.1:8000` / `ws://127.0.0.1:8000`
(см. `preload.js`).

## Состав

- `main.js` / `preload.js` — процесс Electron, окно, IPC-мост.
- `renderer/index.html` — разметка (анкета слева, протокол диалога справа).
- `renderer/app.js` — вся клиентская логика: ассистент-анкета, WS-стриминг и рендер
  partial/stable/final сегментов, выбор модели ASR, маркировка спикеров, привязка аудио↔текст,
  правка сегментов.
- `renderer/audio-capture.js` — захват микрофонов (`CaptureChannel` — непрерывный стриминг по
  каналу; `OneShotRecorder` — разовая запись ответа анкеты).
- `renderer/styles.css` — стили.

## Заметки

- Модель ASR переключается из выпадающего списка в шапке; недоступно во время активной записи.
- Live-сегменты (пока реплика не финализирована сервером) визуально отличаются пунктирной рамкой
  и приглушённым «подвижным» хвостом текста — см. `.segment-live` в `styles.css`.
